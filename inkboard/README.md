# Inkboard

Local e-paper dashboards for the Seeed Studio TRMNL 7.5-inch (OG) DIY Kit running the
Inkboard ESPHome firmware.

- Calendar agendas and a whole-month calendar from your Home Assistant calendars
- Microsoft To Do lists, read-only, from personal or work accounts
- Custom screens built from widgets such as dates, entity values, agendas, and task lists
- Screen rotation, time-of-day schedules, and quiet hours
- No long-lived access token: the App talks to Home Assistant through the Supervisor

See the **Documentation** tab for setup, and the repository README for the full guide,
including the display firmware.
